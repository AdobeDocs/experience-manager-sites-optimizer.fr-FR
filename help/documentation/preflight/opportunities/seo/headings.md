# Audit des titres

L’audit **En-têtes** examine la structure d’en-tête de votre page. Une hiérarchie d’en-têtes claire et ordonnée aide les lecteurs et les moteurs de recherche à comprendre comment votre contenu est organisé. L’audit signale les problèmes tels que les en-têtes qui ignorent des niveaux ou qui apparaissent dans le désordre.

Lorsque l&#39;audit trouve des opportunités, chacune d&#39;elles identifie l&#39;en-tête concerné et décrit le changement recommandé. Pour savoir comment examiner et résoudre les opportunités, voir [Résultats d’audit dans le contrôle en amont](../../audit-results.md).

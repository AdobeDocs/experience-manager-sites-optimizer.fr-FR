# audit de Lorem ipsum

L’audit **Lorem ipsum** détecte le texte d’espace réservé qui a été laissé dans le contenu de votre page. La publication d’une page avec un texte d’espace réservé semble inachevée pour les lecteurs et peut être indexée par les moteurs de recherche. L’audit marque tout texte d’espace réservé afin que vous puissiez le remplacer par du contenu réel avant la publication.

Lorsque l’audit détecte des opportunités, chacune d’elles identifie l’endroit où apparaît le texte d’espace réservé. Pour savoir comment examiner et résoudre les opportunités, voir [Résultats d’audit dans le contrôle en amont](../../audit-results.md).

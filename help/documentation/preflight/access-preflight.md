# Accéder au contrôle en amont

Le contrôle en amont est disponible dans les environnements de création AEM Sites, notamment l’éditeur universel, la création basée sur les documents et l’éditeur de page d’AEM Sites. Le contrôle en amont s’ouvre sous la forme d’un panneau sur la page que vous créez. Dans le panneau, vous [exécutez des audits](./audits.md) sur cette page et le contrôle en amont [affiche toutes les opportunités](./audit-results.md) qu’il détecte pour améliorer la page avant de la publier.

* **Éditeur universel** : l’extension de contrôle en amont s’affiche dans le **rail latéral**. Sélectionnez-la pour ouvrir le panneau Contrôle en amont .
* **Création basée sur des documents** - Ouvrez le panneau Contrôle en amont à partir du Sidekick ou d’un signet dans le contenu de la page prévisualisé.
* **Éditeur de page AEM Sites** - Utilisez le signet Contrôle en amont dans votre navigateur pour ouvrir le panneau Contrôle en amont.

Une fois le panneau ouvert, sélectionnez **Analyser la page** pour lancer un audit de la page active.

Pour obtenir des instructions de configuration, voir [Configuration du contrôle en amont](./setup.md).
